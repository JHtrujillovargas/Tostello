# Tostello

Tienda virtual de ropa y artículos de segunda mano.

## Descripción

Tostello es una boutique de ropa, zapatos, bolsos, juguetes y otros artículos seleccionados de segunda mano. Cada producto es único y se vende en una sola unidad.

## Estado del proyecto

En desarrollo. Actualmente en la etapa de requerimientos y diseño.
